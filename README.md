# Data preparation for the "Quantitative Analysis in R" BA seminar (summer semester 2026)

This repository contains raw data on topics relevant in political sociology and scripts to transform it. You are free to use this material for your research project. 

## Week 4: Subset of the European Social Survey (ESS), Round 11

**Reference**

European Social Survey European Research Infrastructure (ESS ERIC). (2026). ESS11 integrated file, edition 4.1 [Data set]. Sikt - Norwegian Agency for Shared Services in Education and Research. https://doi.org/10.21338/ess11e04_1
